## Design consequence

Because no legally clean "electric mouse" pack could be verified, the
starter character is deliberately **original**: a round golden creature with
a curled teal tuft, teal swirl tail, and amber cheeks. The electric-yellow
mood is preserved without copying any protected character elements.

The voice system is honest about what it is: playful synthesized electronic
chirps, not recordings of any character. User-facing copy says "Spi-spi"
style phrases, which are original onomatopoeia.

## User-imported local packs (not bundled)

Users may add their own character packs under the local data directory
(`~/.local/share/sparkiee/characters/<pack-id>/`). The user is solely
responsible for the rights to any files they add. Local packs are never
included in git commits or npm tarballs; `.gitignore` covers the data
directory conventions, and the engine validates paths so packs cannot read
files outside their own directory.

To add a pack: create the directory, write a `manifest.json` following the
schema validated by `packages/core/src/character-pack.mjs`, add
`sprites/sheet.png` (and `sounds/` for clip-style voices), then select it
from the dashboard character picker. To remove a pack, delete its directory.
